## Virtual keyboard span

Graded on-screen practice uses **white keys F3–G4** (computer keys **A–L**). Lesson content in these modules stays inside that span so virtual and microphone rubrics align for the same lesson. A real acoustic or digital piano can play any octave; optional future **octave shift** or **MIDI** can widen the virtual path.

## Lesson completion

A recorded lesson is marked complete only after the **final practice phase** passes the evaluator (intermediate phases log attempts but do not unlock the next roadmap lesson).
